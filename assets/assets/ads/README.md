광고 카드 위쪽 이미지(가로:세로 4:3)를 이 폴더에 넣는다. 고르는 순서:

1. `브랜드이름.jpg` (예: `파타고니아.jpg`, `맥케이지.jpg`, `K2.jpg`). `ads.json`의 `brandName`과 글자까지 같아야 한다.
2. `ads.json`의 `image` 경로
3. `default.png`: 브랜드별 사진이 없는 광고가 공통으로 쓰는 사진(블러 처리한 패딩, 1200×900). 실제 형식은 WebP다.
4. 위 파일이 모두 없으면 로고 없는 패딩 일러스트(코드로 그림)

파일을 넣은 뒤 다시 빌드·배포하면 자동으로 반영된다.
